# Pls, Dont Kill Me, Piglin!

**Небольшой мод для Minecraft 1.21.11 (Fabric), который меняет поведение пиглинов и хоглинов, делая путешествия по Незеру чуть менее опасными при правильной экипировке.**

## ✨ Особенности

В ванильной игре пиглины не атакуют игрока, только если на нём надета хотя бы одна часть золотой брони. Этот мод расширяет и логически дорабатывает механику:

* 🐷 **Мирные пиглины:** Как и прежде, уважают золото.
* 🐗 **Усмирение хоглинов:** Теперь **хоглины также перестают атаковать игрока**, если на нём надета любая золотая броня (шлем, нагрудник, поножи или ботинки).
* 🛡️ **Гибкость экипировки:** Достаточно иметь всего один золотой элемент брони, чтобы обезопасить себя от обоих видов мобов.

## 🚀 Установка

1. Убедитесь, что у вас установлен **[Fabric Loader](https://fabricmc.net)** для версии 1.21.1.
2. Скачайте и установите **[Fabric API](https://curseforge.com)** (обязательно для большинства модов).
3. Скачайте файл мода (`.jar`) из раздела [Releases](ссылка-на-релизы) или с Modrinth/CurseForge.
4. Поместите скачанный файл в папку `.minecraft/mods`.
5. Запустите игру!

## 🛠️ Требования

* Minecraft 1.21.1
* Fabric Loader
* Fabric API
